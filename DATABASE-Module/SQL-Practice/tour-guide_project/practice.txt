## **🎯 Route 2 Spec: `GET /api/tours/stats`**

Now let's build our summary dashboard endpoint!

### **Your Goal:**

Handle a `GET` request to `/api/tours/stats` to calculate aggregate metrics across all tours.

#### **Requirements:**

- **SQL Query Goal:**
    - Calculate:
        - `COUNT(*) AS total_tours`
        - `AVG(price) AS avg_price`
        - `MAX(price) AS max_price`
        - `MIN(price) AS min_price`
    - From table `tours`.
- **JavaScript Goal:**
    - Use **db.get()** (since aggregate queries return a single summary object!).
    - Handle errors cleanly with a `500` status code and `return;`.
    - Return HTTP **200 OK** with the JSON summary object.

* * *

### **🧪 Expected Postman Output**

**Request in Postman:**

    GET http://localhost:8000/api/tours/stats 

**Expected Response Body (** **200 OK** **):**

    { "total_tours": 4, "avg_price": 497, "max_price": 997, "min_price": 197}
