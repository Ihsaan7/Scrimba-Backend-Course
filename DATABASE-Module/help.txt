 🚀 What's Next: The Final Piece of CRUD (DELETE) 🗑️
You have conquered Reading (SELECT), Writing (INSERT), and Modifying (UPDATE).
The final operation of the foundational database lifecycle is Deleting data.
1. The SQL DELETE Syntax
To permanently remove a record from a table, we use the DELETE FROM statement.
DELETE FROM table_name WHERE condition;
For example, to delete the tour with ID 3:
DELETE FROM tours WHERE id = 3;
⚠️ The Golden Warning Part 2: Just like UPDATE, if you run DELETE FROM tours 
and forget the WHERE id = 3 clause, your database will instantly wipe out every 
single tour in the table! Always write your WHERE clause first.
